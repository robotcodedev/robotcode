## 1. Server: path mapping and stdio mode (Python)

- [ ] 1.1 Add the process-wide table of client URI roots and local path roots to `packages/core/src/robotcode/core/uri.py`: incoming `file:` URIs that match a client root (scheme, host and first path segment compared without case) map to the local root plus the unquoted rest in `_to_path_str`; `Uri.from_path` maps a path below a local root (compared on its POSIX form) to the client root plus the quoted rest; the longest root wins; an empty table changes nothing. Verify with new tests in `tests/robotcode/core/test_uri.py`, which reset the table after each test: `file://wsl.localhost/Ubuntu/home/u/p/a.robot` ↔ `/home/u/p/a.robot` with the root `file://wsl.localhost/Ubuntu/=/`; `file://wsl$/Ubuntu/…` with a `wsl$` root; `file:///c:/work/a.robot` and `file:///C:/work/a.robot` → `/mnt/c/work/a.robot`, and back as `file:///C:/work/a.robot`; `/mnt/c/x` prefers `/mnt/c/` over `/`; a space in the path round-trips percent-encoded; with an empty table every URI and path converts as before. Round trips through `normalized()` run only where the local side is POSIX (skipped on Windows with that reason); the pure conversions run on every platform.
- [ ] 1.2 Add the hidden global option `--path-mapping CLIENT_URI_ROOT=LOCAL_PATH_ROOT` (repeatable, `hidden=show_hidden_arguments()`, marked as internal option for IDE clients) to the root command in `src/robotcode/cli/__init__.py`, split at the first `=`, set the table from it on every invocation, and reject a value without `=` with a usage error. Verify with a new test `tests/robotcode/runner/cli/discover/test_path_mapping.py` on a copy of a suite in `tmp_path`, with the in-process runner: with `--path-mapping file://client.example/share/=<tmp_path as POSIX>/` every item `uri` of `discover all` starts with `file://client.example/share/`; an unsaved document passed on stdin under its client URI is used; without the option the output is unchanged; `--path-mapping nonsense` exits with a usage error.
- [ ] 1.3 In `packages/jsonrpc2/src/robotcode/jsonrpc2/server.py`, let `start_stdio` write the protocol to a duplicate of file descriptor 1 and point file descriptor 1 at stderr, and end the read loop when a read returns no data, so that the server shuts down.

## Watch: RoboCon 2024 tutorial

<div class="rc-split">

<YouTubeVideo id="7Uad_250YuI" title="RobotCode tutorial at RoboCon 2024" />

<div>

This recorded RoboCon 2024 tutorial starts with the RobotCode extension for VS Code and then shows RobotCode's command line tools: the `robot.toml` configuration, profiles, and querying and checking a project from the console.

- Length: ~2 hours.
- Level: Beginner to advanced — basic knowledge of Robot Framework and Python is recommended.

What you will learn:

- Installing the RobotCode and Even Better TOML extensions in VS Code and setting up a project.
- Writing a first test with the Browser library, built step by step in the Debug Console.
- Looking up library keywords and their documentation in the editor.
- Creating a `robot.toml` and running tests from the command line with different profiles, also selecting profiles in VS Code.
- Querying a project's suites, tests and tags and checking its quality with `robotcode`.
- and more...

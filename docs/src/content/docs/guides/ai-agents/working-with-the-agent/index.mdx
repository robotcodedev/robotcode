This tutorial shows how to work with an AI agent on a Robot Framework project, step by step. The steps follow the order in which you get to know a project and work on it: first find out what it contains, then write and run tests, find out why a test failed and debug it, check your changes before a push, and set up the configuration for CI.

Each step explains what you learn, how to ask the agent, what the agent does and why, and what to watch out for. You work with your own project and with the agent you set up on [Setting Up](/guides/ai-agents/setting-up/). What happens behind a request is on [How the Skill Works](/guides/ai-agents/how-the-skill-works/).

## The recorded sessions

At the end of each step, sessions that Claude Code recorded with the RobotCode skill show the step in an example project: the prompts, the commands the agent ran with their output, the files it read or changed, and its answers. They are collapsed; open one to read it. The explanations of the steps quote short excerpts from them.

The sessions were recorded on 2026-10-29 with Claude Code 2.1.312, the model Claude Opus 5.5 (`claude-opus-5-5`) and RobotCode 2.8.0. **You:** marks a prompt and **Agent:** an answer of the agent. `…` marks a part that was left out, *…* a step that was left out, often one in which the agent read the skill's reference files. Paths such as `~/webshop` take the place of the folders on the machine the sessions were recorded on. Nothing else is changed. Another agent, or the same agent on another day, words its answers differently and may take other steps.

## The example project

The sessions run in a small example project: a web shop whose tests use an in-memory Python library, `libraries/ShopLibrary.py`, through the keywords in `resources/`. The Browser library is installed for the shop's web page. The suites cover logging in, the cart, orders and the product search. The tests carry their requirement (`[Metadata]    Requirement    SHOP-…`) and, for some, their risk. `robot.toml` defines the profiles `dev` (Firefox) and `ci` (the staging shop). The instruction file the agent reads is on [Briefing the Agent](/guides/ai-agents/briefing/).

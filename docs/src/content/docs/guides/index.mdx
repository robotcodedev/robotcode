The guides explain how to work with RobotCode in VS Code, in PyCharm, on the command line and with an AI agent; how to configure a project with `robot.toml` and how RobotCode finds the Robot Framework files in it; and practices for Robot Framework code that RobotCode's analysis can follow. Each group of guides starts with an overview of its pages. Have a guide or a tip to share? See [Support & Contribute](/contributing/).

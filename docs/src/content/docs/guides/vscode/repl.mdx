RobotCode's REPL runs Robot Framework statements one by one: import a library, call a keyword and see its result at once, without writing a test. It is a good place to try out a library or to find the right arguments for a keyword.

**RobotCode: Start Terminal REPL**, also in the RobotCode menu (**RobotCode: Show Tool Menu**), opens a terminal named "Robot REPL" in the workspace folder of the active file and starts `robotcode repl` there, with the folder's Python environment and the [configuration profiles](/guides/vscode/configuration/#configuration-profiles) you selected:

Type statements as you would write them in a test, with at least two spaces between the keyword and its arguments. In a workspace with several folders, the terminal carries the folder's name.

What the REPL can do, from history and completion to saving a session as a test and debugging at the prompt, is described in [Interactive Robot Framework with robotcode repl](/guides/repl/).
